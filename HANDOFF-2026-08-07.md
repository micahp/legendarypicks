## Lessons

- Subagent timeout ≠ work not done: check the live transcript before redoing.
- Props table has no league column — join prop_games for league queries.
- ESPN cache is sha256(url)[:32] keyed; the worktree cache (333 MB) is the source of
  truth for summary payloads, main checkout's cache is smaller/different.
- False positives when grepping cache for an athlete id: match exact `"id": "N"` or
  `"N"` boundaries — alternateIds (sdr:) collide.
