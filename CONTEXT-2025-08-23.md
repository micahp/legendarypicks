# Project Context Summary (updated 2025-08-23)

## Purpose
Legendary Picks – Flow-based fantasy platform. Core goals:
• Show users their NBA Top Shot moments (via account-linking/HybridCustody).
• Display daily/past sports games and allow contest creation.
• Contests backed by `LegendaryPicksContest` Cadence contract.

## Current stack
| Layer | What is used |
|-------|--------------|
| Flow  | FCL (`config/fcl.ts`), TopShot, MetadataViews, ViewResolver, HybridCustody |
| Frontend | Next.js 13, Tailwind, React hooks, fetch helpers in `services/**` |
| Sports data | Centralized provider switch in `pages/api/nba/games` (SportsData.io proxy or FastAPI using `nba_api`) |

## Key Components
- `components/MomentGallery.tsx` – manual address input; resilient to missing metadata; shows counts (IDs vs metadata).
- `services/nbaTopShot.ts` – Cadence 1.0 scripts; metadata via ViewResolver; mainnet addresses via env.
- `pages/scores.tsx` – date picker; hits `/api/nba/games?date=YYYY-MM-DD&provider=...`.
- `services/nbaGames.ts` – `getGamesByDate(date, provider?)` calling the centralized Next API route.
- `pages/api/nba/games.ts` – provider switch + retry/cache for SportsData.
- `backend/nba_service.py` – `/api/games/by-date` using `nba_api` ScoreboardV2.
