## Critical lessons (espn-request-budget skill, .claude/skills/)

- ESPN's limit is a COUNT per host (~100), NOT a rate. Pacing never buys budget.
- Shared `paced_http.Fetcher` enforces host_budget=100 + 60s cooldown/reset +
  disk cache (hits don't charge). The MLS ingest completed 510 games in 32 min
  using this — it works when the box is otherwise quiet.
- Do NOT write a retry ladder that assumes 403 is transient (the reconcile
  burned 26 min inside the wall doing exactly this). Fail loudly, wait for the
  host budget to reset, re-run (disk cache makes re-runs free).
- The live dev server (:8096 standings) polls ESPN and competes for the budget;
  run big ingests when the box is otherwise quiet.
- Subagents on this box: NO terminal, and they burn budget on web_extract/ESPN
  fetches. Tell them explicitly to work from local files. The provider was
  switched to DeepSeek mid-session (API 429s on the old provider ate whole
  waves — verify every subagent's output on disk before trusting it).
