## Known gaps the CEO flagged (2026-06-24) — the work

1. **No odds/price stored anywhere.** `props` has `(line, side)` only → EV, breakeven vig, CLV are
   *structurally impossible*. Hit-rate vs line is computable; edge is not. (See `ANALYTICS-BACKBONE.md`.)
2. **Offseason data gap.** NBA/NHL/NFL seasons have **ended** → no live data; `player_stats` for those
   leagues is sparse/stale (NBA only 525). We need a way to acquire + store historical/offseason
   team/player/game data so the app isn't blind ~9 months/yr.
3. **Props are the de-facto parent/source of truth.** That's upside-down — props (a market artifact)
   shouldn't own the game/player graph. Needs a real game→team→player stat spine.
4. **Team stats are a glorified standings** (win%, differential, streak, last-10 via
   `/api/{league}/strength`). No per-game team stats surfaced as a first-class table for non-MLB.
5. **World Cup (soccer) coverage** — full implementation brief exists: `docs/SPEC-world-cup.md`.
   New *sport class* (draws, halves+stoppage+ET+pens, group tables, three-way markets, xG/possession
   boxscore, starting XI/formation). ESPN endpoints already identified in the spec — verify payloads
   before coding (ESPN drifts).
6. **Voids aren't persisted** → cron re-voids the same residue every 30 min (waste + noisy logs).
