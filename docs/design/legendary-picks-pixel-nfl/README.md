## Design principles
- 16-bit/pixel-art sports management aesthetic; atmospheric NFL HQ apartment, arcade game framing, distinct rooms/screens.
- Retain working Legendary Picks routes and real analytics underneath each surface.
- Each prop, forecast, simulation and split must be labeled with source, time and model/experiment status.
- **Numbers, records, player illustrations, team marks and performance claims shown in the images are illustrative mockup content**, not verified Legendary Picks output.
- Before launch, use properly licensed assets or original marks; respect sound preferences, reduced motion, accessibility and mobile performance.
