## Documentation ownership

Architecture defines stable terms and boundaries. Model cards define versioned models, execution, inputs, status and evaluation. Specifications define intended behavior and acceptance tests. Evaluation records comparable cohorts and limits. Research/decisions preserve evidence and rationale, not competing definitions. Archives are historical context only. When evidence changes, update the existing canonical page, add a pinned source, and record any change of identity. Never relabel frozen results. See [AGENTS.md](../AGENTS.md).
