## What shipped

**NHL current season** (`84d4925`, `ce7acdc`, Codex `2dc4c1d`). The 09-21/22 and 09-30/10-01
work had been sitting uncommitted in one tree as two slices; they went in as two commits.
`ingest_nhl_roster.py` publishes the 32-team roster from `api-web.nhle.com`;
`ingest_nhl_logs.py` is game-oriented and atomic per completed game; readiness is
`league-readiness-v3` (`completed_team_results`, `roster_snapshot`). Codex migrated the 2027

rehearsed against clones before either live database was changed; protected-table fingerprints
were unchanged.

**NHL standings carry a season picker** (`bf6c2d4`). The UI was already correct: `SeasonPicker`
renders a static pill when `available_seasons` has one entry, and we held one snapshot. The
league publishes each season's `standingsEnd` at `/v1/standings-season`, so a completed season
is fetched from `/v1/standings/<that date>`. `standings/now` asked for 20252026 returns this
season's table under last season's name. Each snapshot now records the endpoint that answered.
`ingest_nhl_logs.py` defines its own `SOURCE = "nhle.com"`, which shadowed the store's on import;
the alias `STANDINGS_NOW_SOURCE` is deliberate.

**UFC optimizer: a publisher disagreement is not a dead pool** (`d9375ee`). The tab 502'd because
RotoWire's event list and salary feed disagreed over one late replacement (Whitehead in bout 5687
unpriced, McGhee priced with no bout). Each case is now excluded with a count, whole bouts serve,
and the board names what was left out. The salary-sum pairing heuristic from the prior session
was deleted: it derived matchups from DraftKings price symmetry and was what raised.

## Measured today, worth keeping

- **The ingest registry delivers about hourly, not twice hourly.** A full DEV-then-PROD sweep takes
  the hour (DEV `:10`-`:43`, PROD `:43`-`:10`), so the `:22` and `:52` firings land on an active
  unit, systemd drops them, and `Persistent=true` fires one catch-up at `:10`. `settlement`
  declares 30 minutes and cannot get it. The run lock is per database, so the UFC timer's PROD half
  at midnight/noon reports `skipped_lock` and the sweep catches it inside the hour.
- **DraftKings blocks this box entirely**: Akamai 403 on every host including `/`. The draftables
  endpoint is real; this is egress. Recorded in `reference_datacenter_ip_blocks_wayback`.
- **Dev data moved under measurement.** `player_game_logs_ufcstats` read 194 rows on dev, then 251
  an hour later with `ingested_at` still capped at 09-13: a scheduled props-history backfill
  (`ingest_ufcstats_prop_history.py`) copied rows with their original timestamps. The gate's UFC
  2017/2018 blockers cleared themselves. Re-read before concluding from a dev count.
- **Release numbering:** "hotfix" means a patch tag, and Micah says it precisely to prevent a minor
  or major bump. An explicit instruction beats the standing "never patch" rule.
