Existing league cards are preserved; their dated evidence is not automatically current. For each new/changed model maintain definition, objective, architecture, inputs/cutoff, algorithm, predecessor delta, exact code/config/artifact identity, results/cohort, limitations and status. No result is adoption without explicit approval.

The research-only sources referenced by these cards are cross-branch pinned links; this documentation branch does not merge research code.
