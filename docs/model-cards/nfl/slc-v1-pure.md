# SLC V1 Pure

[Registry](README.md) · [SLC](../../architecture/SLC.md)

Minimal historical whole-play control based on frozen V1. Keeps score-clock call, historical event/yardage pool, eligible participants, per-game Dirichlet usage, legal clock/rules/stats and blocker fixes; removes team outcome ratios, formation/coverage outcome conditioning, QB overrides, player outcome multipliers, target roles, labels/filter, playbook overrides, point and streak splits and exact-yardline row filters. Not a live intra-play simulator. Source [design/launcher](https://github.com/micahp/legendarypicks/blob/8a99925f/docs/research/SLC-V1-PURE-2026-11-21.md); [intra-play audit](https://github.com/micahp/legendarypicks/blob/8a99925f/docs/research/SLC-V1-PURE-INTRAPLAY-ORDER-AUDIT-2026-11-21.md). At this pin the design says not yet simulated/calibrated/promoted; no new runtime evidence in this documentation change.
