# SLC sack and turnover outcome-weight audit

**Date:** 2026-11-11
**Status:** Historical event-weight stage scored; the complete V2 sampler funnel remains open.
**Run type:** Offline, deterministic probability scoring. No game simulation or seed run.

## Result

The base exact-situation event distribution was better than the existing team outcome reweights on the clean 2025 holdout. This applies to the complete event mix and each measured dropback drive-killer outcome. The offense-only, defense-only, and combined offense × defense weights all made held-out log loss worse than the league cell model.

| Dropback target | Observed rate | League probability | Offense × defense | League log loss | Matchup log loss | Matchup minus league, 95% game-cluster CI |
|---|---:|---:|---:|---:|---:|---:|
| Sack | 6.594% | 6.540% | 6.576% | 0.24665 | 0.25254 | +0.00589 [0.00416, 0.00777] |
| Interception | 1.522% | 1.602% | 1.542% | 0.08556 | 0.08974 | +0.00418 [0.00275, 0.00570] |
| Fumble lost | 0.496% | 0.611% | 0.587% | 0.03499 | 0.03801 | +0.00302 [0.00207, 0.00410] |
| Interception or fumble lost | 2.018% | 2.213% | 2.129% | 0.10533 | 0.11064 | +0.00530 [0.00373, 0.00694] |

The five-class event log loss / multiclass Brier was **0.94841 / 0.53087** for the league cell; offense-only **0.95696 / 0.53322**; defense-only **0.95846 / 0.53477**; and matchup **0.96762 / 0.53746**. Lower is better. Each paired interval resamples the 272 games, not individual plays.

This does not mean the league cell predicts every team well. Minnesota's 2025 offense had 10.86% sacks per modeled dropback (525 observations); the adapted league cell predicted 6.53% and the combined team weights 7.07%. Minnesota's defense forced sacks on 9.67% (486 observations); the cell predicted 6.57% and matchup weights 7.02%. Team weights moved these estimates in the right direction for those two sack rates, but did not close the gap and worsened overall held-out scoring. Buffalo's offense sack estimate moved the wrong way: observed 7.10%, league 6.49%, matchup 5.68% (521 observations).

All nine pregame EPA offense-by-defense strength groups had worse five-class log loss with matchup weights than with the league cell. The full group results and binary event metrics are in `funnel-results.json`. Group results are descriptive; not every individual event-by-group estimate has enough support for a standalone conclusion.

## Scope and method

- Train on clean, known-penalty-status regular-season plays from 2022–2024; score clean, known-status 2025 regular-season plays.
- Use only nflverse PBP parquet and schedule parquet under `/root/lp-snapshots/nfl-backfill-2026-10-27`. `penalty=false` rows are eligible. Confirmed penalties and unknown penalty labels are excluded from fitting, current-season adaptation, and scoring.
- Rebuild the historical team event ratios, then apply the existing SLC V1.5 season update with `N0=4`. For each target game, include only results available at least 10 hours after their kickoff and before the target's kickoff minus 90 minutes. There were 57 distinct evidence cutoffs across 272 games.
- For each observed dropback with a supported exact down-distance-field cell, score the five-class distribution: sack, interception, fumble lost, incomplete pass, and completed pass. Normalize after the base counts, offense multiplier, defense multiplier, and combined multipliers. Fifteen observed rows lacked the minimum exact-cell support; 18,139 were scored.
- Strength bins use each team's clean 2022–2024 EPA rate, calculated before the test season.

The JSON records source hashes, model counts, fallback counts, team results, all nine strength groups, paired bootstrap intervals, and the exact code hash. This run uses frozen parquet sources directly. It does not use the mutable local SQLite database or claim to reproduce the November 10 database-pinned report.

## What this closes—and what it does not

This closes the offline comparison of the **historical/current-season team event multipliers** on observed dropback contexts. It supports the earlier finding that these multipliers do not improve overall held-out event probabilities. It also shows that a league-level rate can hide large team-specific sack gaps.

It does **not** trace the complete SLC V2 sampler. Formation, coverage, streak, decision-label, player-outcome, QB/scramble, and participant-selection effects were not applied here. Nor does it attribute the low sack and turnover rates in full games between event weights and the situations generated by the engine. The saved 10K run contains no per-play probability funnel. Therefore hypothesis C remains open until a deterministic no-draw scorer evaluates every active V2 stage and its fallbacks on the same observed pre-play contexts.

Fumble lost is measured per dropback here. It is not a rate for all fumbles or for fumbles on run plays. Penalty generation remains off.
