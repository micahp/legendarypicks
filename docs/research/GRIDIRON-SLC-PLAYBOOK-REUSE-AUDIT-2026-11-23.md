# Gridiron and SLC playbook reuse audit

Audited 2026-11-23. Gridiron Physics `main` was `2851ffe6ddc1b2c77fd7ecd7613122a8689f2197`; its playbook research checkout was `ad9880d653dbb3de99e58ffac114fc5919f1e952`. The SLC retro runtime is this branch. The repository code and the local built profiles are separate artifacts; a checkout alone does not necessarily contain every built profile.

**Recommendation:** reuse the existing profile artifacts, selection contracts and autonomous execution work. Do not create a second independent route tree or playbook. First choose whether V1 Complete executes the existing JavaScript autonomous engine through a versioned boundary or extracts its reusable route logic into a shared, separately tested component. The Python retro demonstration is a limited prototype and must not silently become a competing source of truth.

## Actually missing

1. An exported, outcome-free **parameterized route/assignment interface**, plus a bridge from the existing JS implementations to the Python SLC runtime. Existing curl/slant paths are valuable but are not that interface today.
2. The requested complete tree and composable concepts. The inspected historical director has the nine path names listed above; it does not define a general hitch, comeback, corner, drag or wheel route, nor a reusable mesh/stick/four-verticals/flood/smash concept catalog. Slant-flat exists in the autonomous engine. A historical chart label is not proof the other concepts were reconstructed.
3. A validated adapter from resolved, cutoff-safe MIN–SF players and the existing SLC participation field to Gridiron's exact 22 slot IDs and player profiles. The two engines use different identity, formation and position vocabularies. Do not silently flex an ineligible player or import video-game player ratings as NFL truth.
4. A deterministic, outcome-free adapter from autonomous result events and coordinates to SLC's reducer, clock, possession and player/team accounting. Full-game overtime, special teams and clock semantics remain separate work.

## Checks and limits

- Read-only inventory found 32 `*-2025.json` files in the local Gridiron playbook root and 160 `*-20??.json` profiles in both the original research build and the external rev7 snapshot. The research report, not the filename alone, establishes the 2026 Week 7 cutoff and missing participation.
- On Gridiron `main`, `node test/autonomous-schema.mjs`, `node test/autonomous-pass.mjs`, `node test/autonomous-run.mjs`, `node test/autonomous-results.mjs`, `node test/autonomous-perception.mjs` and `node test/autonomous-formation.mjs` passed. The passing test reports 60 existing fixture runs; this is component evidence, not forecast validation.
- `node test/prototype.mjs` failed because its locally read playbook lacks `pregame_2026_comparison.eligible_plays`. The checkout's test and local data are not established as a matching artifact set. No files were altered to make the test pass.
- This audit implements no routes, playbooks, fitting or model changes. It does not promote or modify V1, V1.5, V1.6 or V2.
