# SLC 2025 realism run (exploratory replays, retrospective, not a forecast)

Code: slc-v2 at the pushed commit 2e73f6d0, checked out on the fast host as /root/repro/final-2025 (detached, clean).
Arms: V1 (v1_full_stack); V1.5 (adds --playcall-season-adapt --season-adapt-n0 4.0); V2 (--slc-v2 with the 2019-2024 participation field, 2025 snap counts through week 17, and the kicker table fitted through 2024).
Games: the 272 regular-season games of 2025. Seeds: 30 per game. Box scores and the realism export on (--export-plays).
Batches: 816 (272 games x 3 arms), game-major order.
Inputs: replay-final-noinjury (272 snapshots, 272 streak files). Game-week injury designations are excluded (the injury file has no timestamps; the engine would use Out and Doubtful designations for eligibility). Streak results are used only once available (kickoff + 10 h <= cutoff, target excluded).
Playcall artifact: SLC-PLAYCALL-ARTIFACT-2025.json, fitted on 2010-2024. Its penalty settings were chosen in an evaluation that looked at 2025, so 2025 is a known validation fold, not an untouched test.
Outcome pool: nfl_pbp seasons before 2025. V1.5 adds past-only 2025 evidence from games whose results were available at the cutoff; the target game is never used. V2 does the same through --slc-v2.
Launch: armed to start when the ablation prints ARMS_ABL_DONE. The first game's batches are checked by first-batch-check.py, output in first-batch-check.txt.
