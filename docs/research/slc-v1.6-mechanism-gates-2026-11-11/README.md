# SLC V1.6 mechanism gates — 2026-11-11

## Release identity

This work is on `slc-v1.6`, forked from the frozen `slc-v1.5` tip `77162c0172b56a9d9ffcc34ae85911fb5aa6b3d4`. It does not change the V1.5 default or its historical results. The experimental profile is `--slc-profile v1_6_candidate`; it requires `--playcall-pass-label-mode conditional` and a frozen play-call artifact and streak file.

V1.6 is implemented as a candidate. It is not release-validated: no full-game paired run has been performed on this branch. The historical cohort is development-exposed and does not establish game-level calibration.

## What is implemented

1. **Dropback ordering and clean source eligibility.** A/D/E label effects are applied only after the sampler selects the pass-outcome group. Sack-fumbles have a distinct `sack_fumble_lost` event, so they remain in the first-stage sack/turnover group and cannot enter the conditional throw model. Game accounting records both the sack and lost fumble. Other fumble-lost outcomes remain available to turnover accounting. The conditional model uses only rows with `penalty=0`; tagged, NULL, and unrecognized penalty status rows are excluded. The V1.5 `legacy` mode remains the default.
2. **Yards to go and chain advancement.** V1.6 blends the existing down/distance-bucket row distribution with rows at the exact yards-to-go value when the post-conditioning candidate set has at least 50 rows. The exact-distance weight is `n / (n + 25)`. It falls back to the bucket distribution below that support. The application count, branch, support and fallback are recorded in the play trace and model manifest.
3. **Fourth-down opportunities.** The policy audit tests whether a team-specific go/punt/field-goal policy improves predictions on observed situations. It did not show a reliable improvement, so V1.6 does not change that policy. A separate comparison of historical PBP with the saved SLC-v2 replay found near-historical overall fourth-down frequency but excess fourth-and-1–2 states, alongside more short third downs and higher third-down conversion. The evidence identifies the short-distance chain distribution as the clearest measured mechanism; low sacks and turnovers may also extend drives, but their contribution was not isolated. V1.6 keeps exact-distance yardage conditioning enabled as the bounded chain-advancement correction. The replay predates V1.6, so full-game validation remains pending. See the [fourth-down opportunity audit](fourth-down-opportunity-audit.md) and the decision evidence embedded in V1.6 run manifests.

4. **Coverage outcome weighting is disabled in V1.6.** A read-only walk-forward audit found that no usable 2022 sacks had coverage labels (0 of 1,208), while coverage was present for nearly all usable sacks in 2023–2025. On 17,887 clean, labeled 2025 dropbacks, the 2022–2024 coverage adjustment lowered mean predicted sack rate from 6.76% to 4.72%, against an observed 6.75%; sack Brier worsened from 0.062567 to 0.063208 and event log loss worsened from 0.967961 to 0.979293. Excluding 2022 restored the mean sack rate but did not improve held-out scores over no coverage adjustment. V1.6 therefore forces this weighting off. V1 and V1.5 behavior remains unchanged. The joined rows used for this audit have SHA-256 `0be86a1abbab7dae228246bfd57953d6f190cf257c3ad5d6ba248dadae3e35e6`; the same decision and evidence are embedded in each V1.6 run manifest.

Penalty generation and enforcement remain outside V1.6, consistent with the V1.7 scope.

## Offline results

Both audits used the same read-transaction extract of the development database, covering regular-season weeks 1–18 in 2022–2025. The compact extract SHA-256 is `8b218b81978a7cf13b9912554dcd650fa4ae064a95665fafb435745f1958cbd8` (48,607,232 bytes; 188,282 PBP rows and 176,711 charting rows). The live development database was being updated by ingestion jobs, so the audits use the extract hash rather than claiming the mutable database file itself was frozen. The pass-label JSON also records hashes for the external player and play-by-play parquet sources.

### Conditional pass outcomes

The 2025 holdout contains 17,006 clean pass outcomes across 272 games. The model was fit on 2022–2024.

| Metric (lower is better) | Baseline | Conditional | Paired game-bootstrap 95% CI, conditional − baseline |
| --- | ---: | ---: | ---: |
| Log loss | 0.74575 | 0.69725 | −0.05205 to −0.04502 |
| Brier | 0.47172 | 0.43049 | −0.04417 to −0.03822 |

The fit excluded 980 penalty-tagged rows and no rows with unknown penalty status in this extract. These are conditional scores using observed labels; they do not validate labels generated by a full game.

### Exact-distance yardage and first-down gains

The 2025 holdout contains 31,530 clean run/pass plays across 272 games. The candidate uses exact-distance training support for 88.7% of these plays.

| Metric (lower is better) | Distance bucket | Exact-distance blend |
| --- | ---: | ---: |
| Yardage CRPS | 2.83705 | 2.83651 |
| Line-to-gain Brier | 0.17894 | 0.17799 |
| Third-down line-to-gain Brier | 0.21291 | 0.21213 |

The game-clustered 95% CI for the overall line-to-gain Brier difference is −0.00135 to −0.00058. Third-down support coverage is 77.0%; its result is descriptive and has no separate interval here. The yardage result is small and comes from one development-exposed holdout. It supports a bounded simulator experiment, not production adoption by itself.

### Fourth-down action policy

On 3,580 clean fourth-down situations across 272 games, the league situation-cell policy had log loss 0.54468 and Brier 0.32753. A team-specific policy shrunk toward that baseline had log loss 0.54289 and Brier 0.32565. The game-clustered 95% interval for team-minus-league log loss is −0.00561 to +0.00200, which includes no improvement. The context uses distance and yardline bins; this observed-context audit does not evaluate SLC's generated fourth-down situation mix.

## Decision and next release gate

The pass-label and yardage corrections are implemented behind the separate V1.6 profile. The fourth-down policy stays unchanged because the offline result is inconclusive. Before freezing V1.6, run a bounded paired V1.5-versus-V1.6 full-game evaluation on identical cutoff-safe inputs and seeds. Require legal transitions and reconciled box scores; report sacks, turnovers, gains-to-line by down and distance, fourth-down opportunities/actions, scores and player workload. Do not describe the offline evidence as proof that V1.6 is ready for release.
