## TL;DR
The product's value (Performance / Matchups / Model tabs, projections, fantasy) runs
on **player stats**, which exist for every league — *not* on Bovada prop lines (those
are MLB-only). This session built the per-game-log foundation that powers all of it.

## The two-layer data model (the key reframing)
- **Bovada layer** (Lines, Slate tabs; EV/CLV) → MLB only, in-season only.
- **Player-stats layer** (Performance, Matchups, **Model/projections**) → all 4 leagues,
  Bovada-free. This is where the value and the off-season coverage live.

## What was built
1. **`player_game_logs` table** — sport-agnostic per-game logs: context columns + a JSON
   `stats` line, spine-resolved to `players.id`, indexed. Schema lives in
   `ingest_nfl_logs.py:ensure_table()` (reused by the others).
2. **Per-game ingests** (one per source):
   - `ingest_nfl_logs.py` — nflverse weekly (2024; latest the weekly file serves).
   - `ingest_nfl_pbp_logs.py` — nflverse **play-by-play** (2025; weekly 404s but pbp has it,
     richer: EPA/CPOE/air-yards + computed fantasy pts). **This is the latest NFL season.**
   - `ingest_mlb_logs.py` — Statcast events → per-game hitting lines (H/TB/HR/BB/K).
   - `ingest_nhl_logs.py` — api-web.nhle.com game-log endpoint.
   - `ingest_nba_logs.py` — ESPN box scores (hoopR mirror dead-ends at 2023).
3. **`roster_sync.py`** — walks every ESPN team roster; populates `espn_id`/team/position;
   rebuilds the `active` flag so it means "currently rostered" (was effectively always 1).
4. **`dedupe_nfl.py`** — identity-SAFE: deletes only id-less, zero-reference stub rows that
   shadow a real-id twin (e.g. Mahomes id=121). Leaves distinct same-name players alone
   ("resolve by ID, never name"). Applied: 380 stubs removed.
5. **`analytics/projections.py` + `/api/projections/player/{id}`** — recency-weighted EV +
   floor/median/ceiling + P(over a line), per stat, incl. fantasy points. Marcel-lite.
6. **Model tab** (pages/props.tsx) — was a placeholder; now player search → projections
   table + line checker. Verified live through the tunnel.
7. Fixed a latent bug: `/api/player/{id}/stats` threw `NameError: now` on EVERY call
   (all leagues) — the Performance tab's advanced-stats panel was dead. One-line fix.
