## SBR pre-2018: one-sided, so no no-vig benchmark

Checked the raw files rather than trusting the earlier note. Every pre-2018-19 season records
**exactly one moneyline per game** — one team's price, the other row carrying the total:

| season | games | both ML prices | one | none |
| --- | --- | --- | --- | --- |
| 2007-08 | 1,314 | 0 | 1,314 | 0 |
| 2008-09 | 1,317 | 1 | 1,316 | 0 |
| 2009-10 … 2017-18 | — | 0 | all | 0 |
| 2018-19 | 1,358 | 1,358 | 0 | 0 |

Pollock's Anaheim example (−155/−123) is exactly our row 929; the Los Angeles side (+135/+103)
is not in the file. So the pre-2018 decade cannot produce a no-vig benchmark without inventing
the missing side. The honest alternative is a bounded benchmark from one-sided prices.
