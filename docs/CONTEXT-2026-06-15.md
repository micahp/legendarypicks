# Context Summary — 2026-06-15

## The Pivot

Legendary Picks started as a Flow blockchain dapp (pack rips, fantasy lineups on-chain,
wallet-connected Top Shot moments). Today we killed all of that and reframed the product
around something ESPN can't do: **explain player props with sharp-money analytics in plain English.**

The blockchain stuff was a wedge that never fit. Stripping Flow exposed the real opportunity:
sports fans want to be smarter. They bet on gut feel. The sharp money bets on TS%, EPA,
xwOBA, and Corsi. Nobody bridges that gap in a way normal people can use.

**Old identity:** Flow dapp with sports scores on the side.
**New identity:** Player prop analytics company. "Here's what the sharp money knows that you don't."

### 4. Prop data engine
- **DB schema**: players, prop_games, props, prop_results tables in SQLite
- **API endpoints**: search players, list props, player history with hit rates, aggregate stats, ingest props (POST)
- **Data provider**: Bovada's open internal API (`bovada.lv/services/sports/event/coupon/events/A/description/{sport}/{league}`). No auth, no Cloudflare, live JSON.
- **Scraper**: `bovada_scraper.py` — scrapes MLB/NBA/NFL/NHL, POSTs to ingest endpoint
- **Tested**: 472 MLB props across 7 live games ingested. Real player names, lines, odds.

### 5. Five-tab props page
- **Lines**: Search players, filter by league/market/book. Table of current props.
- **Slate**: Game browser — expand to see per-player prop chips by team.
- **Performance**: EMA-weighted hit rates (L5/L10/L20/season) with trend arrows. Backend computes EMA per market/side.
- **Matchups**: Placeholder — will show player-vs-opponent history with defensive ranks.
- **Model**: Placeholder — will show LightGBM projections vs sportsbook lines with confidence scoring.

### 6. Advanced analytics strategy
- Documented key metrics for each sport (docs/ADVANCED-ANALYTICS-BY-SPORT.md):
  - NBA: TS%, USG%, Pace, Opp DvP
  - NFL: EPA, CPOE, aDOT, target share, DVOA
  - MLB: xwOBA, Barrel%, exit velo, whiff%, xFIP
  - NHL: Corsi, Fenwick, xG, PDO, O-zone%
- Free data packages for all four: nflfastR (1999), hoopR (2002), baseballr (2008), fastRhockey (2010)
- Implementation order: NFL first (deepest data, EPA built in)

## Key decisions made

1. **Bovada is the prop data provider.** Kalshi is fallback. No paid odds APIs needed for MVP.
2. **No paywall yet.** Ship free, build audience, add Stripe later.
3. **NFL-first for advanced metrics.** Best free dataset, most popular betting sport.
4. **Product positioning**: educate fans with sharp-money analytics in plain English. Target fantasy players + prop bettors.
