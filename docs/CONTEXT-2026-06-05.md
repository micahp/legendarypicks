### CDL Data Source

The official Call of Duty League website embeds all match data as server-side rendered
JSON in `<script id="__NEXT_DATA__">`. The client extracts:
- Match status (COMPLETED / PENDING / LIVE)
- Competitor names, abbreviations, scores, and icons
- Start times as Unix timestamps

Matches are normalized to the same shape ESPN returns: `{game_id, date, state, status, home, away}`.

Results:
- **Today (June 5):** No CDL matches scheduled — correct, empty array returned
- **May 29 (last match day):** 3 COMPLETED matches show real scores (CAR 3-0 TOR, C9NY 1-3 MIN, TX 3-0 VAN)
- **June 12 (next match day):** PENDING matches will populate automatically
- **Full season:** 30 matches total across the schedule

### Kalshi CoD Investigation

Checked Kalshi for Call of Duty markets — they existed on match day but are
deleted entirely after settlement (not kept as "settled" or "closed"). The local
`prediction-market-trading/data/orderflow/` has captured JSONL files with real prices
from the live markets, but Kalshi 404s on all CoD tickers post-resolution. Kalshi
is not viable as a permanent CoD data source — only works same-day during the
trading window.
