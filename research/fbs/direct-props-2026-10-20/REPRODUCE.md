# Reproducing the FBS direct-props headline numbers

This file pins every headline number in `RESULTS.md` to the committed CSVs in this
folder. Nothing here needs the model code or the cache -- plain `pandas` on the CSVs
reproduces the table exactly. The model's own scoring pass and these checks use the
same arithmetic and the same seed, so they agree to the printed precision.

Generated by `run_direct_props.py` (branch `research/fbs-direct-props-2026-10-20`).

## Files

| CSV | What it holds |
|---|---|
| `scoring_2025.csv` | 2025 out-of-sample score per market x method: CRPS, cov50/80/90, bias, MAE, beyond-p99, Brier at the real line |
| `decomposition_2025.csv` | model error split: sd_ratio, opp_rmse, and related terms |
| `predictions_<market>.csv` | per-row predictive summaries + per-row CRPS (model and both baselines) |
| `spread_before_after.csv` | Defect 3: CRPS/coverage/sd_ratio before vs after the spread fix |
| `verdict_2025_clustered.csv` | Defect 1: game_id-clustered CRPS deltas + 90% CI + week-block deltas |
| `population_2026.csv` | Defect 4: per-market accounting of every 2026 prop and each filter |
| `scoring_2026_props.csv` | 2026 board per market x method |
| `coverage.csv` | data-honesty coverage counts |
| `params.json` | tuned parameters *after* the spread refit (pre-refit kept as `*_mom`) |

## 1. Coverage (cov50 / cov80 / cov90)

Coverage is read straight off the predictive quantiles in `predictions_<market>.csv`.
Intervals are the *two-sided central* intervals, so the quantile columns are:

| Interval | Columns in the CSV |
|---|---|
| cov50 | `q25`, `q75` |
| cov80 | `q10`, `q90` |
| cov90 | `q05`, `q95` |

(The earlier mismatch -- a "90%" interval actually built from `[q10, q90]`, i.e. an 80%
interval -- is fixed here: the saved columns now include `q05`/`q95`, and `scoring_2025.csv`
computes cov90 from those.)

```python
import pandas as pd
d = pd.read_csv("predictions_pass_attempts.csv")   # any of the four markets
y = d["observed"].values
cov50 = ((d.q25 <= y) & (y <= d.q75)).mean()
cov80 = ((d.q10 <= y) & (y <= d.q90)).mean()
cov90 = ((d.q05 <= y) & (y <= d.q95)).mean()
```

## 2. CRPS and the baseline comparison

Per-row CRPS is committed, so the headline CRPS is a plain mean -- no Monte Carlo needed
at reproduce time:

```python
model_crps = d["crps_model"].mean()      # -> scoring_2025.csv row method=="model"
baseA_crps = d["crps_baseA"].mean()      # -> method=="baseline_A_trailing5_fixed"
baseB_crps = d["crps_baseB"].mean()      # -> method=="baseline_B_position_league"
```

The paired delta and its clustered CI are in `verdict_2025_clustered.csv`:

```python
delta = d["crps_model"].values - d["crps_baseA"].values          # model - trailing-5
# cluster = game_id; 10,000 resamples; seed = 20261020
```

The bootstrap resamples **clusters (game_id)**, not rows, so within-game correlation does
not shrink the interval. The `n_clusters` column reports how many distinct games each
market scored. A per-row unpaired CI (as used before) is *not* reported -- it understates
the delta variance and is why the prior "ADOPT" verdicts were withdrawn.

## 3. Spread before/after (Defect 3)

`spread_before_after.csv` carries, per market, `crps_before/after`, `cov50_before/after`,
`cov80_before/after`, `cov90_before/after`, `sd_ratio_before/after`. The "before" column is
the prior committed model (dispersion fit by method-of-moments on 2018-2024); "after" is
the spread re-fit by CRPS minimisation on 2018-2024 only. 2025 is never used in either fit.

## 4. 2026 board population (Defect 4)

`population_2026.csv` reconciles `props_total` = `dropped_unsettled` + `dropped_no_espn_id`
+ `dropped_unmatched_athlete` + `dropped_no_asof` + `dropped_leak_guard` + `scored`.
The `scored` column equals the rows for that market in `scoring_2026_props.csv` (the
"as-of" method row).
